# 로고·브랜드·공식 웹 자산 활용 기준

확인일: 2026-08-02  
라벨: `OFFICIAL_WEB` 자산 위치 + `TEAM_DECISION` 활용 정책

## 확인된 공식 웹 자산

공식 홈페이지 HTML이 직접 참조하는 주요 자산입니다.

| 용도 | URL | 확인 크기 |
|---|---|---:|
| 미래에셋증권 헤더 로고 포함 이미지 | `https://miraeassetfesta.com/images/pc/main/header.jpg` | 1920×108 |
| 제10회 2026 AI Festival 히어로 | `https://miraeassetfesta.com/images/pc/main/hero.jpg` | 1920×1042 |
| 공모 정보 | `https://miraeassetfesta.com/images/pc/main/info.jpg` | 웹 원본 참조 |
| 일정·시상 | `https://miraeassetfesta.com/images/pc/main/schedule.jpg` | 웹 원본 참조 |
| 유의사항 | `https://miraeassetfesta.com/images/pc/main/caution.jpg` | 웹 원본 참조 |
| 링크 미리보기 이미지 | `https://miraeassetfesta.com/images/og_img.jpg` | 1200×630 |
| favicon | `https://miraeassetfesta.com/images/favicon.png` | 30×30 |

모바일 자산은 같은 구조의 `/images/mo/main/...`에 있습니다. 위 파일은 공식 사이트의
현재 공개 자산 위치를 기록한 것이며, 별도의 팀 사용 허가나 상표 라이선스를 의미하지
않습니다.

## 가장 안전한 활용

- 기술제안서의 대회 식별용 표지에는 공식 대회명과 주제명을 텍스트로 표기합니다.
- 공식 로고·히어로를 써야 한다면 원본 비율과 색을 유지하고, 출처 URL·확인일을
  기록하며, 주최 측이 참가팀 자료에 사용해도 된다고 확인한 뒤 사용합니다.
- 제품 UI는 팀 고유 이름·색·아이콘을 사용해 공식 미래에셋 서비스처럼 오인되지 않게
  합니다.
- 미래에셋증권·네이버·HyperCLOVA X 로고를 합성하거나 변형하지 않습니다.
- 로고를 추천·수익보장 배지, 상품 우열 표시, 광고성 CTA와 결합하지 않습니다.
- PDF·발표·데모에서 “주최/공식 제품”처럼 표현하지 않고 “AI Festival 참가작”으로
  표시합니다.

## 지금 활용할 수 있는 디자인 요소

- 대회명: `제10회 2026 미래에셋증권 AI Festival`
- 공식 주제명: `금융상품 Agent`
- 공식 영문 역할명: `Financial Product Analyst`
- 데이터 상품군: 국내채권·국내 ETF·해외 ETF·공모펀드
- 제안서 정보 구조: 질의 → QueryPlan → 결정론적 실행 → 근거 → 안전 답변

브랜드보다 심사에 직접 기여하는 것은 근거 추적성·정량 정확도·리스크 통제입니다.
MVP에서는 로고 작업을 기능 개발의 선행조건으로 두지 않습니다.
