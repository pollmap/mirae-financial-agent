# 요구사항·준수 기준선

기준일: 2026-08-02  
상태: 오프라인 설명회 전 기준선

## 1. 제품 목적

`OFFICIAL_PDF`

국내채권, 국내 ETF, 해외 ETF, 공모펀드 데이터를 기반으로 자연어 질의에 맞는
상품 정보를 조회·비교·설명하는 금융상품 AI Agent를 만듭니다.

핵심은 단순 키워드 검색이 아니라 다음입니다.

- 서로 다른 네 마스터 스키마 분석·구조화
- 자연어의 상품 유형과 복합 조건 이해
- 상품 검색·필터·연산
- 비교·정렬·순위·집계
- 상품군 교차 질의
- 데이터 근거가 있는 설명
- 데이터가 부족할 때 확인 불가 또는 역질문

공식 영문 표현은 `Financial Product Analyst`입니다. 범용 투자상담이나 개인화
투자추천 서비스로 범위를 확장하는 것이 과제의 중심은 아닙니다.

## 2. 공식 필수 기능

`OFFICIAL_PDF`

1. 국내채권·국내 ETF·해외 ETF·공모펀드 전체를 분석합니다.
2. 상품군별 다른 스키마를 적절히 구조화합니다.
3. 자연어 질의에서 상품군과 조건을 복합적으로 해석합니다.
4. 상품을 검색하고 상세정보를 조회합니다.
5. 조건을 필터링합니다.
6. 필요한 계산을 수행합니다.
7. 상품을 비교합니다.
8. 정렬·순위·집계를 수행합니다.
9. 채권·ETF·펀드 등 상품군을 넘나드는 질의를 처리합니다.
10. 데이터를 근거로 설명합니다.
11. 참조 데이터를 표시합니다.
12. 정보가 부족하면 확인이 필요한 조건을 역질문합니다.
13. 데이터에 없는 내용은 추측하지 않습니다.

현재 `TEAM_DECISION` 구현에서 “설명”은 정확한 상품명·코드·ticker로 단일 상품이 확정된
경우의 source-backed 상품사실·원본 운용전략·benchmark로 한정합니다. target이 없으면
역질문하며, 데이터 밖의 개방형 금융교육·투자 의견은 공식 요구사항으로 확대 해석하지
않습니다. 단순 교차 상품군 개수는 scope별 distinct count로 답하지만 통화·기간·단위·
위험척도가 다른 교차 순위는 계속 fail-closed합니다.

## 5. 답변 원칙과 금지사항

`OFFICIAL_PDF`

### 필수

- 데이터에 근거해 답변
- 참조 데이터 표시
- 확인할 수 없는 질의는 `확인할 수 없음` 명시
- 또는 결과를 바꾸는 핵심 조건을 역질문

### 금지

- 데이터에 근거 없는 수익률 전망
- 단정적 투자 추천
- 데이터에 없는 내용 추측

### 직접 도출되는 안전 규칙

`TEAM_DECISION`

- 결측값을 0으로 치환해 비교하지 않습니다.
- 기간·단위·통화·정의가 다른 숫자를 같은 지표로 순위화하지 않습니다.
- 상품군별 위험척도를 공식 근거 없이 통합하지 않습니다.
- 스냅샷을 실시간 정보로 표현하지 않습니다.
- 상품 선택과 수치 계산을 LLM의 자유 생성에 맡기지 않습니다.
- 내부 chain-of-thought는 노출하지 않고 실행 감사요약을 제공합니다.

## 10. API 예시와 확정 범위

`OFFICIAL_PDF`

확정:

- 평가자가 GET 요청
- 공개 End-point 필요
- URL과 요청·응답 JSON 명세 제출

예시:

```http
GET /answer?question_id={id}&question={평가 질의}
```

```json
{
  "question_id": "Q-001",
  "question": "평가 질의 원문",
  "retrieved_context": "답변 생성에 참고한 검색 문서",
  "think_trace": "사고 · 추론 · 도구 사용 과정",
  "answer": "최종 생성 답변"
}
```

PDF 제목이 `스키마 예시`이므로 경로, 파라미터, 필드 고정 여부와 타입은
`OPEN_QUESTION`입니다. 설명회 전에는 예시와 최대한 호환되는 adapter를 사용하고,
핵심 엔진과 분리합니다.
